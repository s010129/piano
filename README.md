# Nocturne 夜曲鋼琴

用電腦鍵盤彈奏的網頁鋼琴。琴鍵在畫面中下方，每個音都會發出一道光。

直接用瀏覽器打開 `index.html` 就能玩，不需要安裝或建置。

## 鍵位

只用到字母區與數字區。排法對照真實琴鍵：白鍵一列，黑鍵在它上面一列。

| 區域 | 白鍵 | 黑鍵 | 預設音域 |
| --- | --- | --- | --- |
| 低音區 | `Z X C V B N M` | `S D G H J` | C3–B3 |
| 高音區 | `Q W E R T Y U I O P` | `2 3 5 6 7 9 0` | C4–E5 |

右側數字鍵盤的 0–9 等同上排數字。也可以用滑鼠或觸控點擊琴鍵，按住滑過去可以刮奏。

## 功能鍵（方向鍵）

| 按鍵 | M1 一般模式 | M2 曲譜模式 |
| --- | --- | --- |
| `↑` | 切換到 M2 | 切換到 M1 |
| `←` `→` | 降／升八度（−2 到 +2） | 上一首／下一首 |
| `↓` | 延音踏板（踩下／放開） | 開始／暫停／重玩 |

## 音色

標頭的液晶面板可以像電子琴一樣切換音色，點 `‹` `›` 或直接點面板。切換時會試聽中央 C，選擇會記在瀏覽器裡。

| 編號 | 音色 | 特色 |
| --- | --- | --- |
| 01 | 鋼琴（預設） | 琴槌敲弦、低音餘音長 |
| 02 | 電鋼琴 | 調頻合成的音叉聲 |
| 03 | 風琴 | 拉桿風琴，按住就一直響 |
| 04 | 弦樂 | 慢起音、延遲抖音 |
| 05 | 合成器 | 鋸齒波主奏 |
| 06 | 音樂盒 | 放開琴鍵也會自然響完 |

音色都用 Web Audio 即時合成，不需要下載音檔，離線也能用。

## M1 一般模式

每彈一個音，那個琴鍵就會往上飄出一道光柱，一路飄到螢幕最上方。按住越久，光柱越長。同時按下三個以上的音時，畫面中央會顯示和弦名稱。

光的顏色依音高而定，取自史克里亞賓（Scriabin）的色光鍵盤。

## M2 曲譜模式

音符由上往下落，就像音樂遊戲。音符底部碰到琴鍵正上方的金色判定區時，按下音符上標示的按鍵。

- 判定：Perfect ±60ms、Great ±110ms、Good ±160ms，太晚就是 Miss。空按不扣分。
- 滿分 1,000,000，結算時依準確率給 S／A／B／C／D 評級，最佳分數存在瀏覽器裡。
- 可以調整速度（0.5×–1.25×）。
- **自動示範**：點「開始」旁邊的「自動示範」，電腦會直接把整首彈一遍，畫面上會顯示「自動示範中」。演奏途中再點一次就換你自己接手彈。只要有電腦代彈的音，這一輪就不會列入最佳分數。

內建曲目：音階練習、小星星、小蜜蜂、歡樂頌、生日快樂、給愛麗絲、卡農（雙手版）。

### 新增曲目

在 `songs.js` 的 `SONGS` 陣列加一筆即可：

```js
{
  id: 'my-song',
  title: '曲名',
  sub: '副標題',
  level: 1,          // 難度 1–3
  bpm: 100,
  voices: [
    'C4 D4 E4/2 | E4/0.5 F4/0.5 G4 R C4+E4/2',  // 音名＋八度/拍數，R 休止，+ 和弦
  ],
}
```

每個聲部都從第 0 拍開始，所以左右手可以分開寫。音必須在 C3–E5 之間。

## 檔案

- `index.html`：頁面結構
- `style.css`：樣式
- `app.js`：音色合成（Web Audio）、鍵盤對應、特效與判定
- `songs.js`：曲庫與簡譜解析
